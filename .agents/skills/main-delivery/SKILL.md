# FoodShare delivery

The user requires delivery to `main`. Follow [the repository procedure](../../../docs/MAIN_DELIVERY.md). Preserve unrelated changes, respect branch protections, and distinguish the remote commit from CI, deployment and store publication. A feature branch or unmerged PR remains pending delivery.
